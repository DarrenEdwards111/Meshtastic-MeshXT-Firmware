# Changelog

## [0.1.0] - 2025-02-14

### Added
- Initial release of Meshtastic-MeshXT-Firmware
- Smaz short-string compression (254-entry codebook)
- Reed-Solomon FEC with three levels (Low/Medium/High)
- 2-byte packet framing with version, compression, and FEC fields
- MeshXTModule integration with Meshtastic firmware
- Automated setup and flash scripts
- Support for ESP32 and nRF52 boards
- Patch system for clean integration with Meshtastic v2.5.6.0
- Full documentation and troubleshooting guide
